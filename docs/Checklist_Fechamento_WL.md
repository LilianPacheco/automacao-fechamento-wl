# Checklist — Fechamento Quinzenal WL

## Antes de iniciar

- [ ] WhatsApp conectado no computador de Lilian.
- [ ] Mês, ano e quinzena conferidos.
- [ ] Aba de destino correta.
- [ ] Planilha disponível e sem outra edição simultânea.
- [ ] Nome do arquivo oficial mostrado pela automação está correto.

## Antes de importar

- [ ] Todas as linhas aprovadas têm data da mensagem.
- [ ] Pendências e duplicidades foram revisadas.
- [ ] Somente linhas corretas estão como `APROVAR`.
- [ ] Backup automático concluído.
- [ ] Aba de destino reconfirmada.

## Antes de encerrar

- [ ] Fórmulas e valores calculados sem erro.
- [ ] Lista de `OK PENDENTE` resolvida ou registrada.
- [ ] Conferência final realizada.
- [ ] Fechamento enviado manualmente para Deise.
- [ ] Execução marcada como `ENCERRADA`.

> Este checklist apenas confirma passos críticos. Para aprender ou recuperar a operação, consultar `Instrucao_Uso_Fechamento_WL.md`.
